一根青菜隐私政策

生效日期：2026-10-22 适用版本：2.17.0

单一用途

一根青菜是一款由用户主动操作的 Alibaba.com 国际站本地运营工作台，用于管理商品、素材（图片银行及视频）、RFQ、交易、国际物流、相关开放平台能力，以及把用户选择的图库素材发布到用户连接的企业社交账号。扩展不提供广告、跟踪或与该用途无关的数据服务。

处理的数据

### 静态 Pages 与新版 IOP 授权工具

首次连接前的本机保护口令可选；留空时使用随机本机密钥，并把设备恢复材料仅保存在受信扩展本地存储。授权页和工作台设置共用保护，无需重复设置。无口令模式手动锁定后仍须点击解锁，但设备恢复密钥不会因此删除，也不构成额外口令屏障。可随后设置口令；所有模式均不能防护完整浏览器配置被复制。口令不进入 Chrome 同步。

公共授权页面只提供指引、打开插件和转交本次 OAuth 回调；不收集网站密码、App Secret、Token 或口令，不含 Token 后端、分析或录制。商家在插件独立工具页填写自己的应用信息及已登记 Callback。只有固定的 https://one-vegetable-auth.pages.dev 可发送“检测、打开工具、转交回调”消息，不能读取或导出凭据。授权码与 state 会经过浏览器导航及静态托管服务；页面立即移除地址栏参数，使用 no-referrer/no-store，不发送给第三方脚本，但这不保证托管运营商没有请求日志。

插件将回调绑定当前任务、已知标签页、精确 origin/path 和一次性 state，再按所选 TOP 或 IOP 协议直接换取或续期 Token，两种协议的授权包分别保存，不混用 Token；本机保护密钥可共用。当前任务及口令仅驻 service worker 内存，任务 10 分钟过期；后台重启后未完成的任务需重新授权。选择口令保护的授权包使用该口令经 PBKDF2（600,000 次）和 AES-256-GCM 加密保存在受信 chrome.storage.local；解锁后派生密钥材料也持久保存在该本机存储，不保存口令或明文 Token，不进入 Chrome 同步。浏览器重启、扩展更新或禁用后重新启用可恢复已完成的授权，不再空闲自动锁定。没有恢复材料的旧包必须先用原口令解锁一次。工作台手动锁定保留 API 使用的本机派生密钥，但清理 TOP/IOP 两种独立工具的恢复密钥；工具内手动锁定只影响当前协议，重启后仍需显式解锁（口令保护模式需要原口令）。续期前仅落盘请求标识、时间和阶段；结果不明不会自动重发或导出。本机保存失败可再次保存已轮换 Token，不重复平台请求，持久化失败不会报告成功。用户确认后可导出含明文密钥的 credentialInfo.json；应保密保存，不公开或提交到 Git。清除授权或全部本地数据包含独立授权包、恢复密钥和续期回执，不撤销平台授权。

### S3 素材传输

用户可自愿配置 S3 Endpoint、Bucket、Region、根前缀和访问密钥。插件直接访问用户授权的精确存储域名，不经过 oneVegetable 后端。配置使用 AES-256-GCM 加密保存在受信任上下文的 chrome.storage.local，独立、不可导出的设备密钥保存在本机 IndexedDB；不另设口令，可在浏览器重启后使用，但不能防护已被入侵的浏览器配置文件。服务端模式继续由后端加密保存。设置页仅回显非密钥配置和 Access Key 尾号。

只有用户主动确认导入或导出后才传输素材；签名和访问密钥仅在扩展后台使用。图片、清单和对象路径会发送至用户选择的存储，导入图片还会发送至 Alibaba 图库。导入规则保存在本机，不会定时同步。清除 S3 配置或全部本地数据会删除本机密文及对应设备密钥，不删除远端对象或已上传的图库图片。取消或中断的上传可能已被远端接收，请核对后再试；不自动重传。

### 本机传输记录

图库 ZIP/S3 任务在当前站点或扩展的 IndexedDB 保存文件路径、目标分组、文件指纹、请求标识、平台 fileId 和执行状态，不保存图片字节、Base64、访问密钥或完整平台响应。最多保留 100 个任务，每个最多 500 张图片；已完成或取消的记录保留 30 天，未解决记录不自动删除。关闭弹窗或切换工作台页面后继续当前任务，刷新或关闭标签页后只恢复记录，需再次确认才继续。结果不明时不会自动重传；清理记录不删除远端素材。

可信局域网 S3 的 HTTP 连接必须由用户显式启用，仅支持私网 IPv4 和 Path-style；HTTP 不加密网络流量，请勿在公共或不可信网络使用。默认仍使用 HTTPS。

### 视频上传与暂存

用户确认后，本地 MP4 经分片暂存至自选 S3；视频标题和公网 HTTPS 源 URL 或临时签名读取链接交给 Alibaba 拉取。持有签名链接者在有效期内可读取视频。任务保存标题、文件名/大小/指纹、身份与配置标识、对象路径、分片/上传标识、ETag、请求/平台标识、时间及状态，不保存文件字节、Base64、源或签名 URL、凭据或完整响应。插件使用独立 IndexedDB；Node/Worker 数据库实现使用 SQLite/D1。最多 100 个任务，无自动到期清理。刷新后需手工恢复并重选原文件或提供同一 URL，不自动重发未知写请求。取消仅中止本任务未完成分片；清除本地记录不删除已完成 S3 对象或平台视频，远端保留由用户管理。真实上传仅开放 Node local-node 与正式插件，Worker 仍关闭。

### 其他工作台数据

  • 用户主动填写或通过授权向导取得的 App Key、App Secret、Access Token、签名算法和网关地址；
  • 用户在当前页面内存中编辑的商品 Schema 和 RFQ 报价，以及仍保留在本机的旧编辑草稿；
  • 用户主动写入商品时产生的本地任务记录，包括商品 ID、适用的类目/语言、字段指纹或上下架状态快照、requestId、可用的 traceId、任务状态和脱敏错误摘要；
  • 从用户 Alibaba.com 开放平台账号按需查询的商品、图片、视频、库存、RFQ、交易、物流和数据洞察响应；
  • 用户主动选择用于社交发布的单张图库图片、文案、目标 Page/专业账号、发布任务状态和平台返回的帖子标识；
  • 用户主动配对自托管后端时产生的 BFF Origin、设备名称、30 天设备令牌、到期时间和脱敏设备信息；
  • 用户主动点击页面反馈截图按钮后，在当前页面内存中临时生成的当前可见应用区域 PNG；
  • 用于控制评价提醒频率的首次使用、上次提示及评价链接打开时间；
  • 用户主动启动开放平台向导后保存的前置阶段和最后检查时间；该记录不包含任何注册资料值或文件信息；
  • 最近 100 条会话级脱敏诊断，包括操作名、requestId、耗时、错误码和可用的 traceId。

凭证与设置使用 AES-256-GCM 加密后保存在扩展的 chrome.storage.local。本机保护口令可选；设置时用 6–256 位口令经 PBKDF2-HMAC-SHA256（600,000 次）派生密钥，留空时使用随机设备密钥。口令不保存。解锁后派生密钥材料持久写入受信 chrome.storage.local 并与当前密文绑定，以便重启后恢复；它不包含口令或凭证明文，不写入 chrome.storage.sync。手动锁定只隐藏工作台敏感配置，保留后台 API 派生密钥；清除授权或全部本地数据才删除相应密钥。不因空闲、浏览器重启或扩展更新／禁用而自动锁定。商品写入任务也保存在 chrome.storage.local，但不包含 App Secret、Token、完整请求或完整响应；Schema 更新任务仅保存字段指纹，未完成任务保留到核验或恢复，完成任务最多保留 30 天、100 条。商品/RFQ 新编辑仅驻页面内存，不自动保存或恢复；旧 localStorage 编辑草稿不读取、不恢复、不迁移，也不主动删除，可由用户明确清除。平台草稿、批量队列与持久任务不受此变更影响。脱敏诊断也保存在 chrome.storage.session，浏览器会话结束后不作为长期日志保留。扩展不运行自有分析或广告服务，也不把这些数据发送到开发者自有服务器。

chrome.storage.local 与 chrome.storage.session 均设置为 Chrome TRUSTED_CONTEXTS，网页及扩展内容脚本不能通过 Storage API 读取。浏览器重启、扩展更新、重载或禁用后重新启用不会自动锁定，也不再提供空闲自动锁定选项。工作台手动锁定仅隐藏敏感配置、禁止查看及导出，保留后台签名所需的派生恢复密钥，因此正常 API 调用和已获准任务不受影响；重启后仍保留界面锁定。它不是断开授权或停止调用的安全开关。需要停止访问时应清除对应授权或撤销平台授权。旧记录没有可用恢复材料时仍需原口令解锁一次；材料损坏或不匹配不能绕过校验。

若遗忘保险库口令，无法解锁敏感设置；后台是否可调用取决于现有恢复密钥。没有有效密钥时只能明确清除扩展本地数据后重新配置。旧版明文凭证不会再用于真实请求；用户设置新口令后，service worker 会直接完成原位加密迁移，不把旧 App Secret 或 Access Token 返回给页面。

用户主动启动授权向导后，扩展会在本次已知的 Alibaba 开发者注册、应用中心和 OAuth 标签页中运行扩展包内固定代码。注册阶段只返回字段是否完成、协议是否勾选和页面状态，不返回或保存公司名称、注册号、地址、文件名、证明材料内容等字段值；页面提示层只能定位缺失控件，不会填写、勾选或提交。审核中等前置状态只在本机保存原因码和最后检查时间并停止轮询。条件具备后，向导读取用户选择的已有应用配置并校验 OAuth Callback。Alibaba 网站密码不由扩展收集；验证码、滑块、MFA 和密钥安全确认由用户在 Alibaba 页面直接完成。App Secret、OAuth code 和 Token 只在 service worker 内存中处理，code 在校验后立即交换且不落盘。完整凭据仅在用户选择“保存到保险库”时加密存储，或在用户确认明文风险后导出为本地 JSON 文件。

用户也可以在自己部署的 Cloudflare Worker 管理页面主动选择云端授权。此时 Alibaba 网站账号和密码仅在该次 HTTPS 请求及临时 Browser Run 会话内存中处理，不写入 D1、应用日志、审计、截图或浏览器录制。临时任务只保存公开状态和会话标识；遇到验证码、滑块、MFA、密钥安全确认、机器人拒绝或额度不足时立即结束并提示改用本机扩展。云端流程不创建应用、不申请权限、不填写开发者资料，也不代替用户接受协议。授权成功后完整凭据直接在用户自己的 Worker 中加密保存，管理页面不回显密钥。

用户可主动把扩展与自己控制的 oneVegetable BFF 配对，用于 Facebook Page 和 Instagram 专业账号单图发布。Chrome 只为用户填写的精确 BFF Origin 请求可选主机权限。一次性配对码由 BFF 管理员批准后，30 天设备令牌保存在受信 chrome.storage.local；插件界面不回显令牌。设备令牌只允许读取社交目标和创建、查询社交发布任务，不能读取 Meta App Secret、平台 Token、BFF 用户或 Alibaba 凭据。插件本地断开会删除令牌，BFF 管理员也可服务端撤销。

待办事项与 Chrome 同步

扩展工作台把用户输入的待办文字、完成状态、条目标识和创建／更新时间等待办元数据保存到 chrome.storage.sync。用户在 Chrome 中登录 Google 账号并启用相关同步后，这些待办数据会经 Google 的 Chrome 同步服务传输和保存，并可同步到同一账号启用同步的其他 Chrome 浏览器。本功能不使用开发者自建的同步后端，开发者不会通过该功能接收待办内容。

离线时 Chrome 先在本地保存待办变更，联网且 Chrome 允许同步后再同步；关闭同步时数据仍按本地方式保存。本地保存成功不代表云端上传或其他设备接收已完成；同步时机与可用性受 Chrome 设置、网络及存储配额限制。相关行为见 Chrome Storage API。

只有待办及其必要元数据参与本功能的同步。扩展不会把 App Key、App Secret、Access Token、口令、加密密钥材料、凭证保险库密文、授权包或社交后端设备令牌写入 chrome.storage.sync。请勿在待办文字中填写密码、密钥、Token 或其他敏感信息。旧版插件保存在本机的待办不会自动上传；仅在用户点击迁移后才写入 Chrome 同步存储，并按上述 Chrome 同步条件上传。Web 版及其旧待办仍保存在当前站点的本地 localStorage，不参与本次迁移，也不会上传到扩展的同步存储。

数据使用与传输

真实查询和商品写入仅在用户操作并确认后，由扩展 service worker 通过 HTTPS 向用户配置的 Alibaba.com 开放平台网关发送。商品内容更新只发送用户实际修改字段的 Schema 补丁，并在请求受理后通过 Schema 回读字段指纹；商品上下架会在出网前核对商品明文 ID、混淆 ID 和当前状态，并在请求受理后通过商品列表回读结果。商品分组新增会将用户输入的名称和所选父级发送到平台；平台当前没有对应的改名或删除接口。外部图片转存仅在用户明确操作时下载指定公共 HTTP(S) 图片，再上传到用户自己的国际站图库。

社交发布仅在用户选择一张图片、目标和文案并二次确认后，将这些数据发送到用户配置的 oneVegetable BFF。BFF 使用用户自行配置的 Meta 应用和连接令牌调用 Meta Graph API。Cloudflare 模式把图片临时加密隔离地存放在用户自己的私有 R2 桶中；Node 模式存放在用户自己的服务器临时目录。临时图片最长保留 24 小时，发布任务元数据最长保留 30 天。扩展不持有 Meta App Secret、用户 Token 或 Page Token，也不把图片发送到项目开发者控制的服务器。

页面反馈截图只会在用户点击“截取当前页面”后于本机生成，并先展示给用户预览。应用会排除反馈弹窗，并遮罩密码输入框及已标记的凭证、Token、银行账号和买家联系信息。截图仅保存在当前页面内存中，重新截取、删除、关闭反馈框或离开页面后即释放。用户点击“复制截图”时，截图写入本机剪贴板；如果浏览器拒绝图片剪贴板，则下载为本地 PNG。复制与“前往 GitHub 反馈”相互独立，打开 GitHub 不会复制或上传截图，也不会清除当前预览。应用只预填非敏感的运行环境摘要；反馈类型、标题、说明、图片粘贴和最终提交由用户在 GitHub 手工完成。应用不使用 GitHub Token，也不代替用户创建 Issue。用户必须在 GitHub 提交前再次检查公开内容。

扩展工作台只在首次使用满 7 天后检查本地评价提醒时间。选择“以后再说”后至少 7 天内不再提示；成功打开 Chrome 应用商店评价页后永久停止提示。扩展只在 chrome.storage.local 保存上述毫秒时间戳，不使用后台定时任务，不检测用户是否提交评价，也不向开发者发送提醒状态。

扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据只用于提供或改进公开说明的单一用途，不用于个性化广告、信用评估或数据转售。除非用户明确授权技术支持、安全调查或法律要求，开发者不会允许人工读取用户数据。

权限说明

  • storage：保存本地加密凭证、设置、首次使用状态、评价提醒时间、商品写入任务、用户主动配对的社交后端设备令牌，持久保存在本机的派生恢复密钥，以及仅驻当前 Chrome 会话内存的脱敏诊断；也用于通过 chrome.storage.sync 保存和同步待办事项，不新增权限，不同步上述凭证或密钥材料；
  • scripting：用户主动启动授权向导后，仅向本次已知的 Alibaba 开发者注册、应用中心和 OAuth 标签页注入扩展包内固定代码；
  • https://eco.taobao.com/*：调用 Alibaba.com 国际站正式 HTTPS 开放平台网关；
  • 可选 http://*/*、https://*/*：只在用户启动授权向导、确认实际 OAuth Callback、配置自定义网关或 S3、配对用户自己的社交发布 BFF，或主动转存外部图片时，按具体主机请求 Chrome 授权。视频暂存复用 S3 授权，不新增 Manifest 权限；用户可以在日志 → 诊断与数据中逐项撤销。

扩展不申请 cookies、浏览历史、tabs、webNavigation 或必选 <all_urls> 权限。授权向导不创建应用、不代替用户接受平台协议，也不绕过人机验证。平台草稿、正式发品、商品 Schema 更新、商品上下架、商品分组新增、图库分组管理、图片上传、外部图片转存及受控视频上传仅在用户主动操作并确认后发起；其他未经扩展路径真实验收的写能力在扩展后台出网前保持关闭。

数据控制与保留

设置页可以锁定保险库、更换口令和断开社交发布后端。日志 → 诊断与数据可以查看或导出不包含具体值的数据清单、清空会话诊断、撤销额外主机权限，以及彻底删除扩展的凭证、设备令牌、设置、评价提醒时间、商品写入任务、视频任务、旧编辑草稿和诊断。服务端设备应由用户在自己的 BFF 管理页撤销。卸载扩展也会删除 Chrome 管理的扩展本地存储。

清除全部数据会删除本扩展在 chrome.storage.sync 中的待办内容及旧记录，但保留一个不含待办内容的 generation 重置标记，用于防止旧设备上的离线记录重新恢复；不清除其他扩展的数据或更改 Chrome 账号设置。删除向云端及其他设备的传播仍依赖 Chrome 同步；离线或同步关闭时不能保证立即删除这些副本。卸载扩展或仅清除扩展本地存储不保证删除 Chrome 账号云端及其他设备上的同步副本。需要移除同步副本时，应先在扩展内执行清除全部数据并让 Chrome 完成删除同步，必要时再通过 Chrome 的账号／同步管理处理保留的数据。Web 待办需在相应 Web 站点或其浏览器站点存储中单独清除。

安全与限制

扩展页面采用 Manifest V3 CSP，不执行远程代码。App Secret 仅由扩展 service worker 解密并用于签名。恢复密钥材料和密文保存在同一浏览器配置文件，会降低离线防护；复制完整浏览器配置文件的人可能无需口令解密，这不是独立的密码保险箱。运行时 CryptoKey 不可导出不代表持久密钥材料不可提取，也无法保护已解锁的运行时、被恶意软件控制的浏览器或用户设备；高安全要求应迁移到用户控制的 BFF。平台权限、业务资格和接口可用性仍由 Alibaba.com 账号及开放平台实时判定，扩展不会在权限不足时伪造成功结果。
