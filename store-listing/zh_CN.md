# 一根青菜

一根青菜是 Alibaba.com 国际站卖家的本地运营工作台，把商品、图库（图片银行）、RFQ、交易、国际物流和开放平台能力集中在一个 Manifest V3 扩展中。

主要能力：

- 使用 Schema 可视化编辑商品与普通详情；
- 选择图库素材并获得非阻断的详情整改建议；
- 搜索 RFQ、管理本地报价草稿；
- 组合订单资金、物流和履约信息；
- 检索已审计的类型化开放平台能力；
- 查看并清除本地数据、会话诊断和额外主机权限。

扩展不会运行广告或分析服务。凭证使用用户口令加密保存在本机，口令不保存，只由已解锁的 service worker 解密并用于签名。当前 2.0.0 版本尚未完成真实账号验收，真实写操作保持关闭；Web Mock 和自动化结果不代表 Alibaba.com 已接受真实请求。
