# 一根青菜

一根青菜是 Alibaba.com 国际站卖家的本地运营工作台，把商品、图库（图片银行）、RFQ、交易、国际物流和开放平台能力集中在一个 Manifest V3 扩展中。

主要能力：

- 使用 Schema 可视化编辑商品与普通详情；
- 使用 JSON 或 ZIP 导入导出商品，ZIP 可携带并自动处理 `assets` 图片资源；
- 选择图库素材并获得非阻断的详情整改建议；
- 搜索 RFQ、管理本地报价草稿；
- 组合订单资金、物流和履约信息；
- 检索已审计的类型化开放平台能力；
- 复用当前 Alibaba 登录态，从已有应用获取开放平台凭证；
- 查看并清除本地数据、会话诊断、受保护的商品上下架任务和额外主机权限。

扩展不会运行广告或分析服务。凭证向导仅在用户主动启动后访问本次已知的 Alibaba 应用中心与 OAuth 标签页，不收集网站密码或绕过人机验证。凭证使用用户口令加密保存在本机，内容脚本无法读取存储，口令不保存；解锁材料仅保留在当前 Chrome 会话内存中，使页面刷新和 MV3 后台休眠后无需重复输入，浏览器重启、扩展更新/重载、主动锁定或所选空闲时限到期后清除。真实请求只在用户主动操作后发起：受保护的商品上下架、图库分组管理、图片上传和外部图片转存已开放，其他写操作在扩展后台出网前保持关闭。商品上下架会先保存最小化本地任务，再通过商品列表回读确认最终状态，并允许用户明确恢复到操作前状态。
