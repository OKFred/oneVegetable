# 一根青菜

一根青菜是 Alibaba.com 国际站卖家的本地运营工作台，把商品、素材（图片与视频）、库存、RFQ、交易、国际物流和开放平台能力集中在一个 Manifest V3 扩展中。

一根青菜是独立开发的第三方工具，与 Alibaba.com 及其关联公司不存在官方隶属、合作、认可或背书关系。使用前请阅读并遵守 Alibaba.com 平台规则及适用于您业务的规则。

2.20.2 更新：将旧版 TOP 应用资料读取入口移至标题下方的独立浅底区域，使用主题绿色，说明放在按钮下方，补齐上下留白并优化中英文、明暗主题与窄屏展示。读取应用资料不导入旧 Token；授权、续期和保存流程、已有凭据、默认协议及写入能力均保持不变，不新增权限。

已知限制：已核对的授权仍存在 IOP 图片分组范围异常、视频业务拒绝及 TOP 供应商上游错误。相关功能保留准确提示，不用模拟数据代替真实结果。

新用户建议优先连接新版 IOP；已有旧应用可继续连接 TOP，未标记协议的历史授权包及既有设置仍兼容 TOP。两份授权分别保存，可设置并记住默认授权，也可按已验证能力自动选路；请自行确认两份授权属于同一商家，工具不代替身份核验。配置其中一份不覆盖另一份，结果不明的写操作不会跨协议重试。两种协议不承诺功能完全等价，不支持的能力明确禁用，不展示模拟结果。

主要能力（按所选协议及账号权限提供）：

- 总览提供授权剩余时间与分级颜色提醒：低于本次有效期的一半为黄色，低于四分之一或到期为红色；未知有效期不猜测，显示变化不会自动触发续期；
- 使用 Schema 可视化编辑商品与普通详情，新建时按类目选择支持的直接下单或询盘定制类型；
- 对当前页选中的商品进行体检，从建议定位到编辑项，返回后保留结果并可主动复查；评分只读，不会自动提交商品修改；
- 在独立模板库管理公司、物流、包装等安全富文本，填写固定文本变量并按顺序组合最多 10 个模板，预览后插入、追加或确认覆盖；独立插件本机保存，Web 后端共享，保存模板不自动更新商品；
- 模板支持 JSON、携图 ZIP 与 S3 预览交换，图片使用相对路径与校验清单；导入时确认目标图片分组，上传并回读确认后替换图片地址，未知结果不自动重传。ZIP 最大 50 MiB，原 fileId 和凭据不写入导出包；
- 从商品列表选择最多 30 件现有正式商品，预览分组和关键词差异、逐件取舍并二次确认后串行提交。仅更新变化的字段，账号或凭据变化时停止；平台受理后仍等待审核及字段回读。批次回执保留在任务中心，结果不明不自动重发，不增加批量清空分组或自动回滚入口；
- 在适用列表中搜索、显隐和排列可选列，固定选择列与操作列，统一搜索、筛选和行操作入口；筛选仅在确认应用后生效，再次搜索相同条件仍会查询；
- 在独立库存页或共享抽屉只读查询商品/SKU 库存，支持本页、所选及单行查询、进度和停止；空记录及未查询不表示零库存，不推算跨来源总库存，也不修改库存；
- 查看商品橱窗额度和商品，二次确认后加入、移出、调整顺序或替换商品，回读核对结果；结果不明时不自动重试，移出橱窗不会删除商品；
- 使用 JSON 或 ZIP 导入导出商品，ZIP 可携带并自动处理 `assets` 图片资源；
- 从当前页选中的图库图片打开新增商品，按顺序带入主图，选择类目后加载全新 Schema；快捷、引导和高级模式保留图片种子，字段不支持或容量不足时整批拒绝，不截断或覆盖。交接仅在内存中一次使用，刷新不恢复；选择图片不会自动上传、保存草稿或发品；
- 获得非阻断的详情整改建议；商品创建按精确 ID 回读，不扫描整店，未找到目标仍待核对，不重复发品；
- 在素材页分页查看图片和视频，并使用全屏预览；图片支持 24/48/96 条分页，视频关联信息按需查询，平台审核状态与质量分别展示；
- 经用户确认上传本地 MP4（最大 50 MiB，先分片暂存至用户配置的 S3）或公网 HTTPS 视频 URL；正式插件和 Node 本地后端已通过真实上传与回读，Worker 真实上传仍关闭。中断后手工选择任务及原文件或同一 URL，不自动重发未知写请求；平台受理不等于回读确认，完成的 S3 对象和平台视频不自动删除；
- 从视频列表或已回读确认的上传任务选择现存商品，也可在商品编辑页选择和预览已有视频，并只读核对关联；真实关联写入尚未开放，不会因选择视频或商品而自动修改商品；
- 使用 ZIP 导入导出图库素材（最大 50 MiB），包含原图与完整性校验清单，上传前需确认；也可独立连接兼容 S3 的存储，按前缀规则映射图库分组，无需部署后端；
- 在本机传输记录中暂停、核对和恢复 ZIP/S3 任务。关闭弹窗或切页后继续，刷新后需手工确认；已成功项不重传，未确认结果不会冒充整批成功；
- 在统一任务中心查看商品、批量队列、素材传输与视频任务回执，按账号上下文打开来源或核对入口；查看记录不会自动重发、恢复或修改商品；
- 将一张图库素材交给系统分享、导出分享包，或通过用户自己的后端发布到已连接的 Facebook Page / Instagram 专业账号；
- 在 TOP 模式搜索 RFQ 并在当前页面编辑报价，IOP 尚不支持 RFQ；商品/RFQ 新编辑不自动持久化或恢复，离开有修改的表单时确认。旧本地编辑草稿不读取、不恢复、不迁移，也不主动删除；平台草稿、批量队列和持久任务保留；
- 按协议支持范围组合订单、物流和履约信息；订单资金仍仅在 TOP 提供，IOP 不用手续费或假数据冒充实付金额；
- 检索已审计的类型化开放平台能力，包括新增 35 项请求/响应契约、示例和权限/业务限制说明；接入不代表当前账号已获权，受限接口和未开放写操作仍不可调用；
- 库存、商品任务、图库传输和视频核对提供同步延迟提示：平台受理后回读可能仍为旧值，结果不明时先核对，不自动重复提交，也不承诺固定生效时间；
- 通过四步图文引导了解开发者注册、平台审核、应用配置和 OAuth 授权，并在 Alibaba 页面获得不读取资料内容的操作提示；
- 复用当前 Alibaba 登录态，从已有应用获取开放平台凭证；
- 先选择离线授权文件导入或在线连接，再选择 TOP/IOP；支持单份 JSON 或包含两种协议的 JSON 数组，整份校验通过后才导入，历史未标记协议的文件按 TOP 处理；
- 独立 TOP/IOP 工具支持在线授权、续期及 credentialInfo.json 导出，不需要额外部署本机服务。新版 IOP 优先读取现有应用；旧 TOP 入口不可读时需手工填写原应用资料或使用自己的备份，不能用 IOP 密钥代替，也不自动创建旧应用。授权包由用户显式导入并保存到工作台，不自动覆盖另一协议；续期结果不明不自动重试；
- 本机保护口令可选，授权页与设置页共用；留空使用随机本机密钥。已启用口令的旧用户仍可用原口令，浏览器重启或扩展更新不自动锁定；
- 待办可通过 Chrome 同步存储跨浏览器同步，断网时保留本机待同步修改；旧本机待办仅在主动迁移后同步，凭据和密钥不参与同步；
- 在分区设置页管理开放平台凭据、S3 存储、连接与语言；切换分区保留未保存输入，导入规则按需展开；
- 在独立日志页查看脱敏诊断、管理本地数据和额外主机权限；连接后端的管理员还可查看请求诊断和操作审计；
- 手动锁定仅隐藏敏感配置，不中断 API；查看或导出凭据仍需解锁。日志页可查看或清除本地数据、会话诊断、受保护的商品写入及视频上传任务、社交后端设备授权和额外主机权限。

扩展不会运行广告或分析服务。凭证向导仅在用户主动启动后访问本次已知的 Alibaba 应用中心与 OAuth 标签页，不收集网站密码或绕过人机验证。凭证加密保存在本机：可选至少 6 位口令，或留空使用随机本机密钥，内容脚本无法读取存储，口令不保存。解锁后的派生恢复密钥持久保存在受信 `chrome.storage.local`，不进入 Chrome 同步，不保存明文 Token；浏览器重启、扩展更新/重载或禁用后重新启用不再自动锁定，也不再空闲自动锁定。工作台手动锁定仅隐藏敏感配置并禁止查看、编辑及导出，保留后台 API 派生密钥；独立 TOP/IOP 工具恢复记录仍会清理。重新管理敏感信息需显式解锁。旧授权包首次恢复需原口令解锁，清除授权也清理对应恢复材料。密钥材料与密文同机保存会降低离线防护，复制完整浏览器配置文件可能无需口令解密；这不是独立的密码保险箱。真实请求只在用户主动操作后发起：TOP 模式的受保护平台草稿、正式发品、商品内容更新、商品上下架、商品分组新增、图库分组管理、图片上传和外部图片转存已完成验收并开放；IOP 按方法和运行环境独立验收，已补齐商品上下架、图片上传及图片分组新增和改名；仍受既有确认及写入门禁约束，不新增库存写页面。未完成真实验收的 Alibaba 写操作仍在扩展后台出网前阻断。商品内容更新和上下架会先保存最小化本地任务，再通过 Schema 或商品列表回读确认最终状态；上下架还允许用户明确恢复到操作前状态。

社交直发需要用户自己的 oneVegetable 后端和 Meta 应用。插件只在用户主动配对时请求该后端的精确站点权限，并保存 30 天可撤销的受限设备令牌；它不保存 Meta App Secret 或平台 Token。只有在用户选择一张图片、目标和文案并再次确认后，图片才会经用户自己的后端发送给 Meta。

视频上传通过独立受控任务入口开放，不开放通用调试器写入或商品视频关联。任务仅保存标题、文件名与指纹、分片及回执等恢复信息，不保存文件字节、Base64、源 URL、签名 URL 或凭据；提交时视频地址会交给 Alibaba 拉取。视频暂存复用用户已授权的 S3 站点，不新增扩展权限。

商品批量维护复用已开放的商品更新接口，不增加接口权限。任务只保存最小回执、批次和账号上下文、目标字段指纹，不持久化完整 XML 或未提交的编辑规则。平台受理、审核通过和字段回读是不同结果，不承诺固定生效时间；结果不明不自动重发，也不自动回滚。没有新增批量清空分组入口或扩展权限；这些资料用于发布准备，不代表已发布商店或线上部署。
