# 一根青菜

一根青菜是 Alibaba.com 国际站卖家的本地运营工作台，把商品、素材（图片与视频）、库存、RFQ、交易、国际物流和开放平台能力集中在一个 Manifest V3 扩展中。

一根青菜是独立开发的第三方工具，与 Alibaba.com 及其关联公司不存在官方隶属、合作、认可或背书关系。使用前请阅读并遵守 Alibaba.com 平台规则及适用于您业务的规则。

主要能力：

- 使用 Schema 可视化编辑商品与普通详情，新建时按类目选择支持的直接下单或询盘定制类型；
- 在适用列表中搜索、显隐和排列可选列，固定选择列与操作列，统一搜索、筛选和行操作入口；筛选仅在确认应用后生效，再次搜索相同条件仍会查询；
- 在独立库存页或共享抽屉只读查询商品/SKU 库存，支持本页、所选及单行查询、进度和停止；空记录及未查询不表示零库存，不推算跨来源总库存，也不修改库存；
- 查看商品橱窗额度和商品，二次确认后加入、移出、调整顺序或替换商品，回读核对结果；结果不明时不自动重试，移出橱窗不会删除商品；
- 使用 JSON 或 ZIP 导入导出商品，ZIP 可携带并自动处理 `assets` 图片资源；
- 选择图库素材并获得非阻断的详情整改建议；
- 在素材页分页查看图片和视频，并使用全屏预览；图片支持 24/48/96 条分页，视频关联信息按需查询，平台审核状态与质量分别展示；
- 经用户确认上传本地 MP4（最大 50 MiB，先分片暂存至用户配置的 S3）或公网 HTTPS 视频 URL；正式插件和 Node 本地后端已通过真实上传与回读，Worker 真实上传仍关闭。中断后手工选择任务及原文件或同一 URL，不自动重发未知写请求；平台受理不等于回读确认，完成的 S3 对象和平台视频不自动删除；
- 在现存商品编辑页选择和预览已有视频，并只读核对关联；真实关联写入尚未开放，不会因选择视频而自动修改商品；
- 使用 ZIP 导入导出图库素材（最大 50 MiB），包含原图与完整性校验清单，上传前需确认；也可独立连接兼容 S3 的存储，按前缀规则映射图库分组，无需部署后端；
- 在本机传输记录中暂停、核对和恢复 ZIP/S3 任务。关闭弹窗或切页后继续，刷新后需手工确认；已成功项不重传，未确认结果不会冒充整批成功；
- 将一张图库素材交给系统分享、导出分享包，或通过用户自己的后端发布到已连接的 Facebook Page / Instagram 专业账号；
- 搜索 RFQ 并在当前页面编辑报价；商品/RFQ 新编辑不自动持久化或恢复，离开有修改的表单时确认。旧本地编辑草稿不读取、不恢复、不迁移，也不主动删除；平台草稿、批量队列和持久任务保留；
- 组合订单资金、物流和履约信息；
- 检索已审计的类型化开放平台能力，包括新增 35 项请求/响应契约、示例和权限/业务限制说明；接入不代表当前账号已获权，受限接口和未开放写操作仍不可调用；
- 库存、商品任务、图库传输和视频核对提供同步延迟提示：平台受理后回读可能仍为旧值，结果不明时先核对，不自动重复提交，也不承诺固定生效时间；
- 通过四步图文引导了解开发者注册、平台审核、应用配置和 OAuth 授权，并在 Alibaba 页面获得不读取资料内容的操作提示；
- 复用当前 Alibaba 登录态，从已有应用获取开放平台凭证；
- 启动时可关闭保险库解锁提示，并查看或清除本地数据、会话诊断、受保护的商品写入及视频上传任务、社交后端设备授权和额外主机权限。

扩展不会运行广告或分析服务。凭证向导仅在用户主动启动后访问本次已知的 Alibaba 应用中心与 OAuth 标签页，不收集网站密码或绕过人机验证。凭证使用用户口令加密保存在本机，内容脚本无法读取存储，口令不保存；解锁材料仅保留在当前 Chrome 会话内存中，使页面刷新和 MV3 后台休眠后无需重复输入，浏览器重启、扩展更新/重载、主动锁定或所选空闲时限到期后清除。真实请求只在用户主动操作后发起：受保护的平台草稿、正式发品、商品内容更新、商品上下架、商品分组新增、图库分组管理、图片上传和外部图片转存已完成验收并开放；未完成真实验收的 Alibaba 写操作仍在扩展后台出网前阻断。商品内容更新和上下架会先保存最小化本地任务，再通过 Schema 或商品列表回读确认最终状态；上下架还允许用户明确恢复到操作前状态。

社交直发需要用户自己的 oneVegetable 后端和 Meta 应用。插件只在用户主动配对时请求该后端的精确站点权限，并保存 30 天可撤销的受限设备令牌；它不保存 Meta App Secret 或平台 Token。只有在用户选择一张图片、目标和文案并再次确认后，图片才会经用户自己的后端发送给 Meta。

视频上传通过独立受控任务入口开放，不开放通用调试器写入或商品视频关联。任务仅保存标题、文件名与指纹、分片及回执等恢复信息，不保存文件字节、Base64、源 URL、签名 URL 或凭据；提交时视频地址会交给 Alibaba 拉取。视频暂存复用用户已授权的 S3 站点，不新增扩展权限。
