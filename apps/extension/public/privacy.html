一根青菜隐私说明

版本：2.0.0 · 更新日期：2026-08-13

本页随扩展离线提供，用于说明当前构建的数据边界；正式上架前仍需把同内容发布到公开、稳定的 HTTPS 地址。

收集与存储

扩展不运行自有分析或广告服务。用户主动填写的 App Key、App Secret、Access Token 和网关设置保存在本机 chrome.storage.local；商品与 RFQ 草稿保存在扩展自身的 localStorage。

最近 100 条脱敏诊断保存在 chrome.storage.session，只包含操作名、耗时、错误码和可用的 traceId，不包含请求参数、凭证或响应正文。

数据传输

真实查询由扩展 service worker 向用户配置的 Alibaba.com 开放平台网关发送。外部图片转存仅在用户明确操作时下载指定公共 HTTP(S) 图片，并上传至其国际站图库（图片银行）。扩展不会出售数据，也不会把数据用于广告、信用评估或与核心功能无关的用途。

对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据只用于扩展公开说明的单一用途，不用于个性化广告、信用评估或数据转售，也不允许人工读取，除非用户明确授权支持、安全调查或法律要求。

权限

storage 用于本地设置和会话诊断；正式网关主机权限用于调用开放平台。自定义网关和外部图片来源的主机权限按使用场景请求，可在设置页撤销。

删除与控制

设置页可查看不含具体值的数据清单、撤销额外主机权限并彻底清除扩展本地数据。卸载扩展也会删除其本地存储。

当前验证边界

当前版本没有真实账号验收，所有真实写能力保持关闭。Mock 与自动化测试结果不代表 Alibaba.com 已接受真实请求。
