一根青菜隐私政策

生效日期：2026-08-13
适用版本：2.0.1

单一用途

一根青菜是一款由用户主动操作的 Alibaba.com 国际站本地运营工作台，用于管理商品、图库（图片银行）、RFQ、交易、国际物流和相关开放平台能力。扩展不提供广告、跟踪或与该用途无关的数据服务。

处理的数据

  • 用户主动填写的 App Key、App Secret、Access Token、签名算法和网关地址；
  • 用户主动创建的商品 Schema 草稿和 RFQ 报价草稿；
  • 从用户 Alibaba.com 开放平台账号按需查询的商品、图库、RFQ、交易、物流和数据洞察响应；
  • 最近 100 条会话级脱敏诊断，包括操作名、requestId、耗时、错误码和可用的 traceId。

凭证与设置使用用户口令经 PBKDF2-HMAC-SHA256（600,000 次）派生的 AES-256-GCM 密钥加密后保存在扩展的 chrome.storage.local。口令不保存，密钥只在已解锁的 service worker 内存中存在，service worker 重启后保险库自动锁定。草稿保存在扩展自身的 localStorage。脱敏诊断保存在 chrome.storage.session，浏览器会话结束后不作为长期日志保留。扩展不运行自有分析或广告服务，也不把这些数据发送到开发者自有服务器。

chrome.storage.local 与 chrome.storage.session 均设置为 Chrome TRUSTED_CONTEXTS，网页及扩展内容脚本不能通过 Storage API 读取。新建保险库默认不启用空闲自动锁定，用户可主动选择 5、15、30 或 60 分钟。启用后，状态查询不刷新计时，实际读取或更新凭证才刷新。service worker 若更早终止，内存密钥会立即丢失。

遗忘保险库口令时无法恢复凭证，用户只能彻底清除扩展本地数据后重新配置。旧版明文凭证不会再用于真实请求；用户设置新口令后，service worker 会直接完成原位加密迁移，不把旧 App Secret 或 Access Token 返回给页面。

数据使用与传输

真实查询仅在用户操作后，由扩展 service worker 通过 HTTPS 向用户配置的 Alibaba.com 开放平台网关发送。外部图片转存仅在用户明确操作时下载指定公共 HTTP(S) 图片，再上传到用户自己的国际站图库。

扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据只用于提供或改进公开说明的单一用途，不用于个性化广告、信用评估或数据转售。除非用户明确授权技术支持、安全调查或法律要求，开发者不会允许人工读取用户数据。

权限说明

  • storage：保存本地凭证、设置、首次使用状态和会话诊断；
  • https://eco.taobao.com/*：调用 Alibaba.com 国际站正式 HTTPS 开放平台网关；
  • 可选 http://*/*、https://*/*：只在用户配置自定义网关或主动转存外部图片时，按具体主机请求 Chrome 授权。用户可以在设置页逐项撤销。

扩展不申请 cookies、浏览历史、标签页或必选 <all_urls> 权限。图库分组管理、图片上传和外部图片转存仅在用户主动操作后发起；其他真实写能力在扩展后台出网前保持关闭。

数据控制与保留

设置页可以锁定保险库、更换口令、查看不包含具体值的数据清单、导出该清单、清空会话诊断、撤销额外主机权限，以及彻底删除扩展的凭证、设置、草稿和诊断。卸载扩展也会删除 Chrome 管理的扩展本地存储。

安全与限制

扩展页面采用 Manifest V3 CSP，不执行远程代码。App Secret 仅由扩展 service worker 解密并用于签名。本地加密降低静态存储泄露风险，但无法保护已解锁的运行时、被恶意软件控制的浏览器或用户设备；高安全要求应迁移到用户控制的 BFF。平台权限、业务资格和接口可用性仍由 Alibaba.com 账号及开放平台实时判定，扩展不会在权限不足时伪造成功结果。

联系与变更
