一根青菜隐私说明

存储

扩展不含分析或广告。App Key、App Secret、Access Token 和网关设置经 PBKDF2-HMAC-SHA256（600,000 次）派生的 AES-256-GCM 密钥加密后存入 chrome.storage.local；口令不保存，重启或闲置后自动锁定。草稿只存本机。

chrome.storage.local 和 chrome.storage.session 均限制为 TRUSTED_CONTEXTS；诊断不含参数、凭证或响应正文。

Limited Use

请求只发往用户配置的 Alibaba.com 网关；外部图片只在用户操作时转存至图库（图片银行）。数据不用于广告、信用评估、转售或无关用途，遵守 Chrome Web Store Limited Use。

控制与边界

storage 用于设置和诊断，网关与图片主机权限按需使用。用户可清除保险库、撤销权限；卸载会删除本地存储。遗忘口令后须重新配置。本地加密不能防护已被控制的设备，高安全场景应使用自管 BFF。真实写能力在账号 smoke test 前关闭；Mock 不代表 Alibaba.com 接受真实请求。
