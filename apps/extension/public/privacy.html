一根青菜隐私政策

生效日期：2026-09-02 适用版本：2.2.0

单一用途

一根青菜是一款由用户主动操作的 Alibaba.com 国际站本地运营工作台，用于管理商品、图库（图片银行）、RFQ、交易、国际物流、相关开放平台能力，以及把用户选择的图库素材发布到用户连接的企业社交账号。扩展不提供广告、跟踪或与该用途无关的数据服务。

处理的数据

  • 用户主动填写或通过授权向导取得的 App Key、App Secret、Access Token、签名算法和网关地址；
  • 用户主动创建的商品 Schema 草稿和 RFQ 报价草稿；
  • 用户主动上下架商品时产生的本地任务记录，包括商品 ID、平台混淆 ID、原状态、目标状态、requestId、可用的 traceId、任务状态和脱敏错误摘要；
  • 从用户 Alibaba.com 开放平台账号按需查询的商品、图库、RFQ、交易、物流和数据洞察响应；
  • 用户主动选择用于社交发布的单张图库图片、文案、目标 Page/专业账号、发布任务状态和平台返回的帖子标识；
  • 用户主动配对自托管后端时产生的 BFF Origin、设备名称、30 天设备令牌、到期时间和脱敏设备信息；
  • 用户主动点击页面反馈截图按钮后，在当前页面内存中临时生成的当前可见应用区域 PNG；
  • 用于控制评价提醒频率的首次使用、上次提示及评价链接打开时间；
  • 最近 100 条会话级脱敏诊断，包括操作名、requestId、耗时、错误码和可用的 traceId。

凭证与设置使用用户口令经 PBKDF2-HMAC-SHA256（600,000 次）派生的 AES-256-GCM 密钥加密后保存在扩展的 chrome.storage.local。口令不保存。为避免 MV3 service worker 休眠后反复要求用户解锁，派生密钥材料会在解锁后写入仅驻内存的 chrome.storage.session，与当前密文版本及最后活动时间绑定；它不包含凭证明文，浏览器重启、扩展禁用/更新/重载、用户主动锁定或空闲超时后会被清除。商品上下架任务也保存在 chrome.storage.local，但不包含 App Secret、Token、完整请求或完整响应；未完成任务保留到核验或恢复，完成任务最多保留 30 天、100 条。草稿保存在扩展自身的 localStorage。脱敏诊断也保存在 chrome.storage.session，浏览器会话结束后不作为长期日志保留。扩展不运行自有分析或广告服务，也不把这些数据发送到开发者自有服务器。

chrome.storage.local 与 chrome.storage.session 均设置为 Chrome TRUSTED_CONTEXTS，网页及扩展内容脚本不能通过 Storage API 读取。新建保险库默认不启用空闲自动锁定，用户可主动选择 5、15、30 或 60 分钟。启用后，状态查询不刷新计时，实际读取或更新凭证才刷新。service worker 普通休眠不会结束当前 Chrome 会话的解锁状态。

遗忘保险库口令时无法恢复凭证，用户只能彻底清除扩展本地数据后重新配置。旧版明文凭证不会再用于真实请求；用户设置新口令后，service worker 会直接完成原位加密迁移，不把旧 App Secret 或 Access Token 返回给页面。

用户主动启动授权向导后，扩展会在本次已知的 Alibaba 应用中心和 OAuth 标签页中运行扩展包内固定代码，读取用户选择的已有应用配置并校验 OAuth Callback。Alibaba 网站密码不由扩展收集；验证码、滑块、MFA 和密钥安全确认由用户在 Alibaba 页面直接完成。App Secret、OAuth code 和 Token 只在 service worker 内存中处理，code 在校验后立即交换且不落盘。完整凭据仅在用户选择“保存到保险库”时加密存储，或在用户确认明文风险后导出为本地 JSON 文件。

用户也可以在自己部署的 Cloudflare Worker 管理页面主动选择云端授权。此时 Alibaba 网站账号和密码仅在该次 HTTPS 请求及临时 Browser Run 会话内存中处理，不写入 D1、应用日志、审计、截图或浏览器录制。临时任务只保存公开状态和会话标识；遇到验证码、滑块、MFA、密钥安全确认、机器人拒绝或额度不足时立即结束并提示改用本机扩展。云端流程不创建应用、不申请权限、不填写开发者资料，也不代替用户接受协议。授权成功后完整凭据直接在用户自己的 Worker 中加密保存，管理页面不回显密钥。

用户可主动把扩展与自己控制的 oneVegetable BFF 配对，用于 Facebook Page 和 Instagram 专业账号单图发布。Chrome 只为用户填写的精确 BFF Origin 请求可选主机权限。一次性配对码由 BFF 管理员批准后，30 天设备令牌保存在受信 chrome.storage.local；插件界面不回显令牌。设备令牌只允许读取社交目标和创建、查询社交发布任务，不能读取 Meta App Secret、平台 Token、BFF 用户或 Alibaba 凭据。插件本地断开会删除令牌，BFF 管理员也可服务端撤销。

数据使用与传输

真实查询和商品上下架仅在用户操作并确认后，由扩展 service worker 通过 HTTPS 向用户配置的 Alibaba.com 开放平台网关发送。商品上下架会在出网前核对商品明文 ID、混淆 ID 和当前状态，并在请求受理后通过商品列表回读结果。外部图片转存仅在用户明确操作时下载指定公共 HTTP(S) 图片，再上传到用户自己的国际站图库。

社交发布仅在用户选择一张图片、目标和文案并二次确认后，将这些数据发送到用户配置的 oneVegetable BFF。BFF 使用用户自行配置的 Meta 应用和连接令牌调用 Meta Graph API。Cloudflare 模式把图片临时加密隔离地存放在用户自己的私有 R2 桶中；Node 模式存放在用户自己的服务器临时目录。临时图片最长保留 24 小时，发布任务元数据最长保留 30 天。扩展不持有 Meta App Secret、用户 Token 或 Page Token，也不把图片发送到项目开发者控制的服务器。

页面反馈截图只会在用户点击“截取当前页面”后于本机生成，并先展示给用户预览。应用会排除反馈弹窗，并遮罩密码输入框及已标记的凭证、Token、银行账号和买家联系信息。截图仅保存在当前页面内存中，重新截取、删除、关闭反馈框或前往 GitHub 后即释放。用户点击“复制截图并前往 GitHub粘贴”时，截图写入本机剪贴板；如果浏览器拒绝图片剪贴板，则下载为本地 PNG。应用只打开预填的公开 GitHub Issue 页面，不上传截图、不使用 GitHub Token，也不代替用户粘贴图片或提交 Issue。用户必须在 GitHub 提交前再次检查公开内容。

扩展工作台只在首次使用满 7 天后检查本地评价提醒时间。选择“以后再说”后至少 7 天内不再提示；成功打开 Chrome 应用商店评价页后永久停止提示。扩展只在 chrome.storage.local 保存上述毫秒时间戳，不使用后台定时任务，不检测用户是否提交评价，也不向开发者发送提醒状态。

扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：数据只用于提供或改进公开说明的单一用途，不用于个性化广告、信用评估或数据转售。除非用户明确授权技术支持、安全调查或法律要求，开发者不会允许人工读取用户数据。

权限说明

  • storage：保存本地加密凭证、设置、首次使用状态、评价提醒时间、商品上下架任务、用户主动配对的社交后端设备令牌，以及仅驻当前 Chrome 会话内存的派生解锁材料和脱敏诊断；
  • scripting：用户主动启动授权向导后，仅向本次已知的 Alibaba 应用中心和 OAuth 标签页注入扩展包内固定代码；
  • https://eco.taobao.com/*：调用 Alibaba.com 国际站正式 HTTPS 开放平台网关；
  • 可选 http://*/*、https://*/*：只在用户启动授权向导、确认实际 OAuth Callback、配置自定义网关、配对用户自己的社交发布 BFF，或主动转存外部图片时，按具体主机请求 Chrome 授权。用户可以在设置页逐项撤销。

扩展不申请 cookies、浏览历史、tabs、webNavigation 或必选 <all_urls> 权限。授权向导不创建应用、不代替用户接受平台协议，也不绕过人机验证。图库分组管理、图片上传、外部图片转存和商品上下架仅在用户主动操作并确认后发起；其他真实写能力在扩展后台出网前保持关闭。

数据控制与保留

设置页可以锁定保险库、更换口令、查看不包含具体值的数据清单、导出该清单、清空会话诊断、断开社交发布后端、撤销额外主机权限，以及彻底删除扩展的凭证、设备令牌、设置、评价提醒时间、商品上下架任务、草稿和诊断。服务端设备应由用户在自己的 BFF 管理页撤销。卸载扩展也会删除 Chrome 管理的扩展本地存储。

安全与限制

扩展页面采用 Manifest V3 CSP，不执行远程代码。App Secret 仅由扩展 service worker 解密并用于签名。本地加密降低静态存储泄露风险，但无法保护已解锁的运行时、被恶意软件控制的浏览器或用户设备；高安全要求应迁移到用户控制的 BFF。平台权限、业务资格和接口可用性仍由 Alibaba.com 账号及开放平台实时判定，扩展不会在权限不足时伪造成功结果。
