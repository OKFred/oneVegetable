# 列表显示列与自动扩展查询

商品、图库列表、订单表格右上角提供“显示列”：搜索、勾选、恢复默认。设置只存本机列 ID，三类页面互不影响；图片可隐藏，选择、名称/ID、操作列保留。图库卡片不受影响。

商品标题下的 ID 使用列表返回的 `detailUrl` 打开 Alibaba 页面，没有地址时为纯文本。不会拼接商品链接，也不会为链接逐条请求 Schema。

## 字段来源

- 商品：`alibaba.icbu.product.list` 的关键词、类目/分组 ID、创建时间、负责人、类型、语言、型号、RTS、规格品、智能编辑、主图数量、水印、原审核状态及混淆 ID。产品分/评分问题数来自既有 `getProductScore`。
- 图库：`alibaba.icbu.photobank.list` 的原始文件名、归属人、分组 ID、原图 URL；路径由已读取的分组树缓存拼出，未知分组保留 ID。列表不返回图片尺寸，继续使用实际图片加载结果，不伪造尺寸。
- 订单：创建时间、币种来自列表适配；平台没有返回金额、币种时使用 null，不再假定零美元。已付金额、支付状态、物流状态、首票承运商/运单来自既有资金与物流聚合。银行账号不开放为列表列。

新增列默认隐藏。官方字段内容不翻译，应用标签支持中文/英文。日期时间沿用 `YYYY-MM-DD HH:mm:ss`，长值限宽并可悬停查看。

## 请求与隐私

- 显示列入口位于操作列表头。显示扩展列后自动查询当前页（默认显示的产品分也自动查询），翻页后按已选列加载；普通列不触发详情查询。进度、停止和失败重试位于表格底部，完成后收起，不占用顶部工具栏。
- 每次只处理一行，相邻记录间隔至少 300ms，不自动重试。订单一行调用资金和物流两类只读接口，多列共享该结果。
- 可停止后续调度、重试失败行；翻页、筛选、语言或工作区变化会丢弃迟到的结果。身份和凭据上下文变化时出网前拒绝继续，响应后再次检查。
- 内存缓存最长 5 分钟，以运行模式、身份、凭据配置、接口语言和记录 ID 隔离。订单抽屉和产品分原入口共用请求缓存；抽屉的 Vue Query key 按页面实例隔离，避免新登录用户看到旧缓存。
- 本地列偏好只保存版本和列 ID；损坏数据回退默认，“清除全部本地数据”清理偏好。负责人、运单号继续标记为反馈截图遮罩区域。

## 验证

2026-09-10：首轮手动模式的本地真实 Node BFF 只读抽样通过。按用户补充需求切换自动模式后，商品/图库新增字段、商品链接、自动产品分和订单资金/物流查询正常；资金、物流 availability 均 available，聚石塔详情继续 jushita-only。复查发现独立的 listProductGroups 连续返回 502/GATEWAY_ERROR，因此最新综合真实报告保留 passed=false，不能宣称所有真实接口通过。没有商品、图库或其他平台 mutation。

脱敏回执和截图仅在忽略目录 `artifacts/list-columns-real/`。可在现有隔离本地 BFF（8886）和 Web（4286）运行时显式执行：`ONE_VEGETABLE_LIST_COLUMNS_REAL_SMOKE=1` + `pnpm exec tsx scripts/smoke-list-columns-real.ts`。脚本使用已有本机测试登录文件，不引导创建账号、不保存完整平台响应。

自动测试覆盖列显隐/持久化/固定列、上下文变更、缓存到期、自动加载/停止/继续及正式 MV3 页面；模拟数据仅来自 `mock/data`，不代表真实插件账号验收。

商品工具栏紧贴表格；上下架不可用原因仅在点击具体操作时提示，不占据常驻空间。商品和图库列表缩略图为 80px，图片预览自适应填充可用视口并保留缩放、旋转。

为保留 4.1 MB 扩展预算，standalone AJV 生成器将重复 `$ref` 编译为共享校验函数，不删除规则、不引入运行时代码生成。尚未部署 Worker、合入主线或提交商店。

本地质量检查：`pnpm check` 通过（830 单测，三端构建、契约漂移、双语和商店静态检查）；Worker 测试 1 项、BFF replay 2 项通过。扩展独立 Profile 回归 2 项通过。正式扩展总大小 4,062,464 字节，未调整 4.1 MB 门槛。
