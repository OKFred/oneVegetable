# 日志页面

- 主导航顺序：版本更新 → 日志 → 设置。
- `#/logs`：BFF 管理员默认查看请求诊断，其他模式默认查看诊断与数据。
- `#/logs/requests`：服务端请求记录、requestId 检索、筛选、分页及过期记录清理。
- `#/logs/audit`：服务端操作审计；与请求诊断共用当前检索的 requestId。
- `#/logs/local`：脱敏诊断刷新、导出、清空；独立插件另提供额外主机权限管理、本地数据清单及确认短语清理。

管理后台不再查询或展示请求诊断与操作审计。设置页不再加载诊断、主机权限或本地数据清单，保留凭据、存储、连接和语言设置。

分区按需加载；保留原来的列偏好键和后端权限。服务端请求诊断与操作审计只向已登录的 BFF 管理员显示，直接访问其哈希路由不会令普通用户或独立插件发起管理接口请求。账号上下文变化后重新检查权限，并丢弃旧分区的迟到结果。

迁移不增加新 API、扩展权限或平台调用，也不会自动清理日志、撤销权限或删除本地数据。危险操作仍需原有确认。
