# 商品视频选用与关联

## 范围

从 `origin/staging` 的 v2.9.0 基线创建 `codex/product-video-association`。商品编辑复用视频库，选择已有视频用于主图或详情。仅处理有平台商品 ID 的现存商品；不上传、删除视频，不改变上下架，不把关联操作合并进 Schema 保存。

新建商品须先取得平台 ID。选择和预览不写入平台；关联是独立的立即写操作，必须再次确认商品、视频及关联位置。

## 使用入口

商品列表点击“编辑”，加载现有商品后可见“商品视频关联”。点击“选择视频”搜索已有视频，支持分页、预览和主图/详情用途选择。三个编辑模式共用该入口；不会把未保存的 Schema 内容一起提交。

Mock 模式可以演示二次确认、关联和回读；真实模式可以选择、预览，但关联按钮仍禁用并提供原因提示。存在本地待核对回执时，可手工进行只读核对。刷新不会自动重发，其他窗口持有执行锁时不能重复执行。“清除全部本地数据”包含关联回执，但不会修改平台关联；执行期间禁止清理。

## 文档核对（2026-09-21）

- [主图关联 50089](https://developer.alibaba.com/docs/api.htm?apiId=50089)：`alibaba.icbu.video.relation.product.main`，免费、需授权，必填 `video_id`、`product_id` 均为 String；示例为 `model=true`、`msg_code=00000`。
- [详情关联 50088](https://developer.alibaba.com/docs/api.htm?apiId=50088)：`alibaba.icbu.video.relation.product.detail`，免费、需授权；响应示例含无效的 `结果/code/info` 占位值，不据此猜测真实成功码。
- [关联查询 50709](https://developer.alibaba.com/docs/api.htm?apiId=50709)：使用加密视频 ID，返回加密商品 ID；继续按公开解密接口核对商品。

两个写方法的文档没有明确说明 ID 是否加密、覆盖旧关联的细节、取消关联或恢复方法。因此不能把“有免费接口”表述为“账号已验收可用”。新能力标记 mutation / documented，`realCallEnabled=false`，不进入任何真实环境默认写白名单。

## 安全边界

- `associateProductVideo` 为 mutation；`verifyProductVideoAssociation` 仅只读。Node/Worker/插件的真实关联仍在出网前拒绝，选取和只读核对可用；Mock 演示不能用作真实成功证据。
- 普通用户不能写入；仍需管理员、CSRF、凭据上下文、契约和逐操作授权。无 BFF 的插件保持独立运行。
- 不混用明文/加密视频 ID；先以明文 ID 查询视频并核对加密 ID，再进行精确商品检查。数字 ID 不做不安全的 JS Number 转换。
- 回执保存到本机并按身份/凭据上下文隔离；先持久化再发送。存储失败不能降级为无记录请求。
- 不自动重试写操作。超时/断线/无法解释的响应记为结果不明；成功响应和回读确认分开。刷新后不重发，只允许手工核对。
- 回读只证明所选视频与目标商品的关联，不证明不存在其他关联，也不宣称已恢复旧关联。不以“未查到”证明写入失败。
- 待核对与结果不明阻止新的关联尝试。核对请求有数量上限，不能扫描全店或无限查询。

## 后续真实验收门槛

1. 确认测试账号、非重要商品、已有视频及当前主图/详情关联基线。
2. 查明请求 ID 语义、替换/恢复方式；如只能通过官方页面恢复，应先明确人工恢复路径。
3. 再次确认允许修改的具体商品与关联类型，单项执行、保留脱敏 requestId/traceId，回读并对照官方视频库。
4. 出现未知结果立即停止，不自动改第二个商品，不调用未文档化私有接口。
5. 分别记录 Node、正式 MV3 与 Worker 的验收状态，未验收环境不开放；不自动部署或上架。

本轮不为验证这些写接口而更换商品视频。视频上传、批量关联、转码及视频 S3/ZIP 传输后置。
