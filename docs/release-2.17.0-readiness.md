# 2.17.0 发布候选

检查日期：2026-10-22。基于 `codex/iop-existing-feature-parity` 准备，不修改已经发布的 `v2.16.1` Tag 或 ZIP。

## 用户可见变化

- 扩展 IOP 商品、库存和图片适配，集中展示协议覆盖、参数限制与验收状态。商品上下架保留持久任务、只读核对及一次性恢复；库存不增加新的写入界面。
- 订单提供销售与采购视角，查询、分页、选择、详情和缓存按角色隔离。IOP 公开订单详情保留真实总金额及商品行，不用手续费或默认值代替已付金额。
- 授权向导聚焦当前步骤，统一“连接新版应用 / 连接旧版应用”，保留离线导入及步骤后退。IOP 说明为“功能陆续接入中，具体请关注平台官方自身开发进度。”；英文同步。旧 TOP 仅面向已有旧应用的用户，不自动创建应用或替代密钥。
- 设置将默认、配置、清除和本机保护操作分开；清除对应授权时同步清理工具残留。修正嵌套弹窗层级、授权页间距和总览按钮高度，视频请求绑定实际授权上下文。
- 工作台锁定仅隐藏敏感配置，不中断后台 API；查看与导出仍需解锁。旧版没有可用恢复密钥时需原口令解锁一次。授权页仅在就绪后显示“继续授权另一种”，完整在线授权备份移到设置并核对与当前配置匹配。

## 明确保留的限制

- IOP 图片分组查询仍存在返回范围不匹配的真实失败回执。继续严格校验，不伪造空目录、扫描全库、移动或重复上传。双授权在出网前选择支持的协议，失败后不跨协议重试。图片分组删除及依赖可信列表的核对不能宣称已经真实通过。
- IOP 视频查询仍有平台拒绝回执，视频上传/结果和关联没有全部完成验收；RFQ、资金、橱窗等并非与 TOP 完全等价。界面明确提示，不回退 Mock。
- 已有真实写入与恢复记录见 `docs/iop-existing-feature-parity.md`；本轮发布回归不重新发送商品、库存或素材写操作，不重新执行 OAuth 或 Token 续期。
- 当前按钮尺寸开发分支保持独立，本候选不擅自合并其他未纳入的功能分支。
