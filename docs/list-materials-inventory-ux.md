# 列表、素材与库存体验

本迭代适用于 Web、BFF 和独立扩展工作台。开发分支为 `codex/list-materials-inventory-ux`；不自动部署 Worker 或提交商店。

## 列表与搜索

- 表头“操作”旁可搜索、全选/全不选、拖拽或上下移动可选列；三态全选不受搜索列名影响。
- 选择列固定最左，操作列固定最右；二者不能隐藏或移动。行操作集中在菜单中。
- 列显隐和顺序保存在本机 V2 偏好，选择记录不持久化。翻页、筛选或身份变化会清空本页选择。
- 商品、图片、视频、订单、库存及其他适用列表复用两行工具栏：第一行搜索框占满剩余宽度，右侧为搜索按钮；第二行筛选和业务操作统一靠右。窄屏操作自动换行。有搜索按钮的列表不再重复展示刷新。
- 再次搜索相同条件仍会重新查询。详情核对、失败重试和没有搜索入口的任务刷新不受影响。
- 筛选弹窗编辑副本，只有“应用”生效；取消、遮罩和 Esc 不修改已用条件。服务端条件与“仅本页”条件明确分区。
- 列设置浮层适配可用视口高度，搜索框及底部操作保持可见，列清单独立滚动。

## 商品与库存

- 产品分只展示平台数值，不添加总分；可见单元格才排队查询，隐藏、离页及后台页面停止后续调度。
- 库存在订单之后独立显示，路由 `#/inventory`；商品行菜单与独立库存页复用抽屉和缓存，不增加库存写操作。
- 库存页提供“查询本页库存”“查询所选库存”与可点击的状态；可切换商品/SKU 接口，显示进度并停止后续查询。批量只处理当前页，复用缓存，至少间隔 300ms；未查询或平台空记录不显示为零库存。
- 上下架记录统一由商品任务中心管理，不在列表底部重复展示。
- 编辑失败通过可关闭对话框展示，保留 requestId、traceId 与脱敏诊断。智能详情关联错误只提供处理指引，不自动转换或重发。

## 素材与编辑

- 导航名称为“素材 / Assets”，包括“图片 / Images”和“视频 / Videos”。旧路由与业务存储键不重命名。
- 图片按 24/48/96 条服务端分页，未知总数明确显示，不用本页条数代替；列表只点图片或预览操作才打开预览。
- 图片与视频共用全屏预览，右上角提供原链接、信息与关闭图标；关闭视频会释放媒体。视频关联信息主动展开后加载。
- 旧商品/RFQ 本地编辑草稿不读取、不恢复、不迁移，也不再弹出清理提示；不会自动删除已有存储。显式本地数据清理入口仍保留。
- 新编辑只驻当前页面内存。离开有修改的业务表单时确认；列表搜索、筛选、界面语言及主题不算业务编辑。批量队列、平台草稿与持久任务仍保留。
- 扩展已有保险库且锁定时，启动弹出可关闭的解锁框；关闭后可使用设置、帮助等页面，不重放写操作。

视频上传、分片暂存、保守恢复与真实验收边界见 [视频上传后端](video-upload-backend.md)。
