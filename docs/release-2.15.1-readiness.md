# 2.15.1 发布准备

记录日期：2026-10-14。本版仅补齐授权倒计时颜色及非敏感时间元数据，不增加扩展权限、Alibaba 方法或真实写能力。

## 范围与兼容

- 剩余有效期严格低于本次有效期的 50% 时为黄色，严格低于 25% 或已经到期时为红色；恰好 50% 保持正常，恰好 25% 为黄色。
- 使用当前 Token 获取时间或最近成功续期时间计算比例，不能使用权限快照时间、配置导入时间或更新时间。失败续期不重置起点。
- 旧授权没有起点记录时保留现有七天提醒，未知有效期继续显示未知，不推测永久有效或固定授权时长。
- Web/BFF、Node 凭据文件与插件导入保留兼容；TOP 仍为默认，显式 IOP 配置不被自动替换，不自动回退协议或 Mock。
- 新增的摘要字段为可选 Unix Epoch 毫秒时间，不返回密钥；复用既有加密文档和成功续期记录，无新增数据库 migration。
- 本地每分钟更新显示，语言和颜色变化不会触发 Token 刷新或新增业务请求。

## 真实授权核对边界

本轮独立 TOP 重新授权及刷新前后的商品列表只读调用通过，但一次刷新被平台以 `param-refresh.token.expired` 拒绝。该结果不能声明为自动续期已通过，也不能把刷新失败等同 Access Token 已失效。新授权仅保存到本机忽略目录，线上既有 IOP 配置未替换；没有商品或素材写入。

既有 IOP 续期验收仍独立保留，不因本次 TOP 结果而更改协议。固定时长 TOP 应用的刷新限制与用户重新 OAuth 授权指引继续有效；未知到期时间不能为了展示颜色而补造。
