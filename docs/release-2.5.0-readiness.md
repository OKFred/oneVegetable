# 2.5.0 候选包验收

本版本尚未提交 Chrome Web Store，不代表已上架或 Worker 已部署。

## 范围

- 插件与 Web：图库 ZIP 导入导出、部分上传失败保护、商品任务回读与详情链接。
- Web/BFF 与插件：加密 S3 配置、前缀映射和可选自动创建图库目录。插件独立直连，无需 BFF 配对。
- 不增加永久权限，不引入账号或 Mock 数据到正式包。

## 运行时证据

- 扩展 E2E 使用正式 MV3 包和隔离 Chromium：首次引导、双语、设置与保险库持久化、service worker 重启、权限门禁、压缩图片图库 ZIP 预校验。
- 真实插件只读：15 个一级分组、24 张当前页素材、测试目录父子 ID 正确，见 `docs/gallery-s3-live-validation.md`。
- ZIP 上传与失败分支通过组件测试，未在本轮新做真实上传或商品写操作。
- 插件 S3：正式构建的隔离 E2E 已验证配置密文、后台重启恢复和非工作台发送者拒绝。真实 S3 验收使用仅增加精确测试域名预授权的隔离副本，成功 PUT 图片/清单、LIST、GET + SHA-256、后台重启后测试和清除配置；并非正式包原生权限弹窗验收。细节见 `docs/extension-s3-validation.md`。

## 包体预算

加入 S3 直连、加密存储、映射界面及双语文案后，解包约 4.06 MB；总预算调整为 4.1 MB，i18n 从 300 KB 调整为 310 KB。首屏仍低于原有 250 KB（约 115 KB），后台仍低于 100 KB（约 83 KB）；权限、敏感内容和其余分块门禁不变。这是项目内部预算，不是 Chrome 商店上限。

## 发布边界

候选包通过后仍按 feature → staging → master → annotated tag / GitHub Release 流程发布。先核对最终 SHA-256，再上传商店；不移动或复用 v2.4.0。

正式提交前仍需在未预授权的 Chrome 中点击 S3“加密保存”，人工允许精确域名并确认成功提示。本轮原生弹窗等待超时，未将其记作已通过。
