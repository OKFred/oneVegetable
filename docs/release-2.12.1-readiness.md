# 2.12.1 发布准备

检查日期：2026-09-26。基线：`0d18fcda335b10d31db9b31f25ecea8326ebe15a`（2.12.0），本版为视频选用、回执安全与包体优化补丁。

## 功能与边界

- 视频卡片、列表和已回读确认的上传任务提供“用于商品”，复用商品搜索、分页与预览。未确认的上传不提供该入口。
- 选择和取消不修改商品。确认关联前需要精确读取视频及商品，账号/凭据变化停止旧流程。
- 矛盾成功标记、异常响应及写后校验失败保持结果不明，不视为可自动重试的明确失败；严格校验只读核对结果。
- **真实商品视频关联在 Node、Worker、插件继续关闭**。现阶段只有离线模拟关联测试通过；由于官方账号暂不可登录，真实主图/详情关联及恢复未验收，不作为可用写功能宣传。
- 仅保留 AJV 使用的中英文语言包，增加构建防回归检查。不提高任何包体门槛，不增加扩展权限。
- 没有新增 migration、请求权限或数据采集；不执行 Alibaba 业务写入、线上部署、商店上传或审核提交。
