# 2.12.0 发布准备

检查日期：2026-09-23。范围：列表、素材、库存与编辑体验优化。

## 功能与安全边界

- 统一列表搜索、筛选弹窗、三态选择、列显隐/排序与行操作菜单；列偏好保存在本机，选中记录不持久化。
- 库存成为独立工作区；产品分按可见区域加载；商品上下架回执统一进入任务中心。
- “素材”包括图片与视频，复用全屏预览和信息面板；图片仅点缩略图或预览操作才打开，服务端分页支持未知总数。
- 编辑不再自动保存或恢复商品/RFQ 本地草稿；离开有修改的表单需要确认。旧编辑数据不读取、不自动删除；批量队列、平台草稿与任务不受影响。
- 插件启动时已锁定的保险库提供可关闭解锁提示；不新增永久 Manifest 权限，不保存口令、不重放写操作。
- Node 本地与独立插件支持公网 HTTPS 地址或最大 50 MiB 本地 MP4 上传，使用已配置的私有 S3 分片暂存及平台回读。真实上传和回读已在本迭代受控验收通过；Worker 真实上传仍关闭，不提供视频删除/改名，不新增商品视频关联写入。
- 平台“已受理”不等于上传已完成；结果不明必须核对，不自动重发。已完成远端对象和平台视频不会自动删除。
- 既有 ZIP 1,500,000 字节、解包 4,100,000 字节及各分块预算保持不变。

实现与真实验收边界见 [界面迭代](list-materials-inventory-ux.md) 和 [视频上传](video-upload-backend.md)。自动化回放不代替真实平台验收。

## 升级说明

- 后端新增 `0014_video_upload_tasks.sql`，仅保存视频任务元数据和回执。Node 沿用启动迁移；Worker 升级须先备份 D1、执行已审核 migration 后再部署。本次发布准备不操作远端数据库。
- 已验证 2.11.0 正式 ZIP 的原始校验和，使用隔离 Chrome Profile 升级到 2.12.0；17 项检查通过，覆盖加密凭据、解锁、S3 配置、界面偏好、列偏好 V1→V2 和传输任务手工恢复。旧编辑草稿留在存储中，但不会自动恢复。
- 用户若通过 BFF 使用新版前端，应同步升级后端契约；独立插件不依赖 BFF。回退后端代码前应保留数据库备份和任务记录，不自动执行逆向迁移。
