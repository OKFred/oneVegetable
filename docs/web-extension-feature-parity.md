# Web 与插件体验对照

检查基线：2.17.0，2026-10-22。本文区分界面共用、运行环境差异和平台能力限制，不将界面存在视为真实 API 验收通过。

## 本轮统一

| 场景               | Web（Node / Cloudflare）                                  | 独立插件                                 |
| ------------------ | --------------------------------------------------------- | ---------------------------------------- |
| 授权入口           | 设置 → 开放平台凭据 → 一键配置；管理员无需先转到管理后台  | 设置 → 开放平台凭据 → 一键配置           |
| 协议选择           | 复用新版 IOP / 旧版 TOP 选择弹窗                          | 同一共享弹窗，先处理必要的本机保护       |
| 配置与更新         | 对应协议弹窗中的导入、手动填写、一键配置，普通按钮等高    | 对应协议弹窗中的导入、手动填写、连接入口 |
| 清除               | 移至授权卡片，独立二次确认；仅清除所选协议                | 授权卡片上的清除，同时清理本机工具残留   |
| 检查与续期         | 对应协议内测试连接 / 刷新 Token / 刷新状态                | 同样按对应协议处理，不跨协议自动重试     |
| 总览续期的配置入口 | 统一返回设置                                              | 返回设置                                 |
| 管理后台           | 复用设置中的授权卡片与配置组件，不再单独维护 TOP 连接按钮 | 管理页面能力由是否连接 BFF 决定          |

Web 的“一键配置”如实引导：在插件完成在线授权并导出 `credentialInfo.json`，然后在当前 Web 设置页导入。已有文件或完整凭据可直接导入 / 手动填写，不必安装插件，也不要求另行部署 Node 授权服务。

Cloudflare 现有旧 TOP Browser Run 入口保留在展开的其他方式中，用户主动点击才启动；新版 IOP 不会误用它。点击向导、选择协议或打开配置不会自动写入凭据、刷新 Token 或执行 Alibaba 业务 mutation。

## 必须保留的运行差异

| 功能           | Web / BFF                                                               | 独立插件                                              | 保留原因                                               |
| -------------- | ----------------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------ |
| 登录与凭据保管 | 工作台身份、管理员权限、服务端加密；配置由该服务用户共用                | 浏览器本机加密、可选保护口令、手动隐藏敏感信息        | 凭据所有权和安全边界不同，不能把本机口令描述用于服务端 |
| 在线授权与回调 | 普通网页不能读取任意 Alibaba 页面或监听其他标签页，使用插件授权文件衔接 | 受信后台、精确运行时域名权限、已知 OAuth 标签页       | 不添加网页窃取跨站信息的“自动配置”，不新增永久权限     |
| 默认授权       | 沿用服务端已有默认协议与按能力选路；本轮不新增默认协议写接口            | 可显式选择并保存本机默认协议                          | 不用“配置”冒充更换默认，不随统一界面修改选路           |
| 授权 JSON 数组 | 兼容读取，但在对应协议弹窗只导入当前协议，确认明确影响服务端所有用户    | 向导可一次导入 TOP / IOP 各一份；对应协议弹窗仍有隔离 | 本轮不新增跨两个服务端档案的原子批量导入契约           |
| 模板           | BFF 数据库共享模板                                                      | 本机模板，可用 ZIP / S3 迁移                          | 独立插件不强制依赖 BFF                                 |
| 社交发布       | 后端配置 Meta、连接账号及发布目标                                       | 通过可撤销设备配对连接社交后端                        | 插件不保存 Meta App Secret / 平台 Token                |
| 待办           | 当前浏览器本地数据                                                      | Chrome sync 与本机兼容迁移                            | 不能将浏览器同步承诺为 Web 跨设备同步                  |
| S3             | 后端校验、签名与网络访问                                                | 受信后台签名及用户批准的精确域名权限                  | 界面和任务模型可共用，网络权限来源不同                 |

商品、图片、视频、订单、库存、模板、任务、日志等工作区主体来自共享 UI，不另造一套 Web / 插件业务页面。可用按钮依赖当前账号、授权协议、运行时白名单与平台返回，不为“统一”扩大写入权限或回退 Mock。

## 平台限制不作为界面差异修复

- IOP 图片分组范围校验、视频能力和 TOP 续期的既有平台限制继续保留准确提示；本轮未重新授权、续期或用写调用测试它们。
- TOP / IOP 两份授权不相互替换。没有旧 TOP 应用的新用户优先按现有 IOP 引导操作。
- 不能用一个账号的通过结果推断所有商家都有相同权限。

## 截图与验证边界

本轮前置界面对照截图位于忽略目录 `artifacts/web-extension-parity-20261022/`。涉及真实授权的页面只查看摘要，不采集密钥、Token 或原始响应。

组件测试覆盖 Node / Cloudflare 入口、管理员隔离、所选协议确认清除、双语向导和打开入口不写入；浏览器回归覆盖设置与管理两个入口、中英文、桌面 / 窄屏、等高按钮、弹窗关闭及导入 / 手动填写。离线回放、界面检查与真实平台调用的结果需分开记录。
